Projects I've shipped

🩺 GenAI · Healthcare · Live Demo
Medical AI Reviewer
Agentic, evidence-grounded RAG system for clinical claim review

Ingests raw medical-record PDFs, indexes them into a vector database, and evaluates each claim against nurse-authored InterQual clinical criteria — returning a verdict, confidence score, and evidence-grounded justification with page citations, all surfaced through an Angular reviewer dashboard.

  • Two-stage retrieval: dense similarity search over Pinecone followed by hosted BGE reranking for precision.
  • Grounded LLM evaluation: strict-JSON reviewer with automatic model fallback and verdict/confidence normalization.
  • Clinical-aware chunking: token-budgeted, section-scoped chunks tagged with diagnoses, medications, and lab values.
  • Built-in observability: RAGAS-style retrieval-quality scoring, trace IDs, token accounting, and latency telemetry per evaluation.
