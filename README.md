# 🩺 Featured Project — Medical AI Reviewer

An **agentic, evidence-grounded RAG system** that reviews medical claims against InterQual clinical criteria — and shows its work.

- 🌐 **Live Demo:** <https://captivating-appreciation-production-bbf1.up.railway.app/>
- 💻 **GitHub Repo:** <https://github.com/kapil-suthraye/Capstone>

**What it does:**

- Ingests raw medical-record PDFs with structure-aware parsing and clinical-aware chunking
- Indexes chunks into Pinecone with per-claim namespaces for evidence isolation
- Two-stage retrieval: dense similarity search + hosted BGE reranking
- Grounded LLM evaluation returning a verdict, confidence score, and page-cited justification per criterion
- RAGAS-style retrieval-quality scoring, trace IDs, token accounting, and latency telemetry
- Angular reviewer dashboard for upload, side-by-side PDF review, and evidence cards

**Tech Stack:** FastAPI · LangChain / LangGraph · OpenAI · Pinecone · RAGAS · Angular · Docker
